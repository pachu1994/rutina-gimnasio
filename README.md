# rutina-gimnasio

Una pequeña app local para llevar el seguimiento de pausas, movilidad y entrenamientos de la rutina personal.

## Archivos

- `index.html` — interfaz principal de la app
- `sw.js` — registro mínimo de service worker para uso local

## Uso

Abre `index.html` en el navegador y usa la app localmente. Los datos se guardan en `localStorage` del navegador.
